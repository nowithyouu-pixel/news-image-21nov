A pure-stdlib Python program that draws the world news of Saturday 21 November 2026 as a one-page newspaper front page — masthead, lead story on Iran's strikes on US bases in Bahrain, and six more stories from Ukraine, Shenzhen, The Hague, Antalya, New York and Sinaloa — and writes it to `/output/entry.png`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The run is deterministic (same bytes every time), uses no network and no third-party packages, and finishes in under a second.
